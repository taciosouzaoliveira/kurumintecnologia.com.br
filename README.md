# kurumintecnologia.com.br

Site da Kurumin Tecnologia: consultoria de infraestrutura, redes, automação e cloud para pequenas e médias empresas.

Site estático publicado pelo GitHub Pages, com domínio próprio e HTTPS.

## Estrutura

```
.
├── index.html              # página principal
├── cases/
│   ├── index.html          # lista de cases
│   └── wifi-pousada/       # case: rede Wi-Fi estruturada numa pousada
├── 404.html
├── CNAME                   # domínio do GitHub Pages
├── robots.txt
└── sitemap.xml
```

## Novo case

1. Copie a pasta `cases/wifi-pousada/` com outro nome.
2. Troque textos, topologia e fotos (sem metadados de localização).
3. Adicione o case em `cases/index.html`, no destaque de `index.html` e no `sitemap.xml`.
